# A 风格分组图标

24 个透明背景 PNG，统一为 128 × 128。服务保留品牌色，功能组使用彩色符号，地区使用旗帜图片。TW 分组按用户设置使用中国国旗，仍代表台湾节点。它们只影响显示，不改变地区分流。

全部素材来自 [Koolson/Qure Color](https://github.com/Koolson/Qure)。感谢原作者；Qure 要求转载注明出处，图标仅供学习参考，不用于商业或牟利，相关标志版权归各自权利人。完整说明见 [Qure README](https://github.com/Koolson/Qure#readme)。

素材去掉透明外边距，保持比例缩放并居中，不改变标志形状。[sources.json](sources.json) 记录每个图标的来源与 SHA-256。PNG 发布路径与分组名一致，两个单文件脚本及通用脚本共用同一套资源。
