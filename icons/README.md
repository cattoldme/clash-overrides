# C 风格分组图标

24 个透明背景 PNG，统一为 128 × 128。服务保留品牌色，七个功能组使用浅色线条，地区使用旗帜图片，适合深色界面。它们只影响显示，不影响分流。

- 服务 Logo 和旗帜来自 [Koolson/Qure Color](https://github.com/Koolson/Qure)。感谢原作者；Qure 要求转载注明出处，图标仅供学习参考，不用于商业或牟利，相关标志版权归各自权利人。完整说明见 [Qure README](https://github.com/Koolson/Qure#readme)。
- Proxies、AI、Streaming、Final、Auto、Fallback、Manual 来自 [Lucide](https://github.com/lucide-icons/lucide)，分别为 network、sparkles、clapperboard、route、zap、arrow-left-right、sliders-horizontal。线条颜色为 `#e4e5ec`，许可保留于 [LICENSE.lucide](LICENSE.lucide)。

素材去掉透明外边距，保持比例缩放并居中，不改变标志形状。[sources.json](sources.json) 记录每个图标的来源与 SHA-256；Lucide 的 source_sha256 对应已设置上述线条颜色的 SVG。PNG 发布路径与分组名一致，两个单文件脚本及通用脚本共用同一套资源。
